隐私协议

更新日期：2026‑09‑21

1. 数据处理说明

Developers Tools（域名：tools.huangfeng.uk）全部工具功能仅在用户浏览器本地执行。您输入的文本、JSON、图片、密钥、密码等所有数据，不会上传到网站服务器，不会经过第三方中转。

网站不会收集、存储、备份您在工具内输入的任何业务数据。关闭页面后，临时内存数据自动清除。

2. 统计与Cookie

本站可开启Vercel Web Analytics网页访问统计，仅统计页面访问、访客来源等匿名汇总数据；不会获取用户输入内容。

网站不设置用于追踪的第三方Cookie，仅浏览器必要会话存储。广告拦截插件可以完全屏蔽统计脚本，不会影响工具功能。

3. 第三方服务

本网站为纯静态HTML站点，无后端接口。所有工具逻辑运行于本地浏览器，不会主动向外部第三方发送用户数据。

页面可能加载CDN公共资源，CDN服务商可能收到普通访问日志，但不会收到您的工具输入内容。

4. 用户责任

请不要在工具输入框粘贴密码、私钥、身份证、密钥等高度敏感信息。虽然数据不上传服务器，但您本地浏览器、截图、录屏会造成信息泄露风险。

5. 协议修订

我们有权随时更新本隐私协议，更新后的版本发布在本页面，不再单独通知用户。请定期访问本页面查看最新条款。

6. 联系

如对隐私条款有疑问，可通过项目GitHub页面提交Issue联系我们。

Privacy Policy

Last Updated: 2026‑09‑21

1. Data Processing Statement

All tools on Developers Tools (domain: tools.huangfeng.uk) run locally in your web browser. Any data you enter including text, JSON, images, keys, passwords will NOT be uploaded to our server or any third‑party server.

We do not collect, store or back‑up any of your input data. Temporary in‑memory data will be cleared once you close the browser tab.

2. Analytics and Cookies

This site may use Vercel Web Analytics for anonymous aggregated page‑view statistics. No user‑input content will be captured.

The website does NOT use tracking third‑party cookies. Only essential browser local storage may be used. Ad‑blockers can block analytics scripts completely without breaking tool functions.

3. Third‑party Services

This is a pure static HTML website without backend API. All business logic executes inside your browser. User‑generated data will not be sent out to external services voluntarily.

Public CDN assets may be loaded; CDN providers may receive general access logs, but never receive your tool input content.

4. User Responsibilities

Please do NOT paste highly sensitive data such as passwords, private keys, ID numbers or secret keys into input boxes. Even though data is not uploaded, local screenshots, screen recording may cause information leakage.

5. Policy Modification

We reserve the right to revise this Privacy Policy at any time. Revised policy will be published on this page without individual notification. Please review this page periodically.

6. Contact

If you have questions about this privacy policy, please submit an Issue via our GitHub repository.
